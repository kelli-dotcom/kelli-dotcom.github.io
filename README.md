# kelli-dotcom.github.io

Come in. Everything here has its place, and nothing is missing.

The live site for Kelli Reeves-Jennings — founder of CRTA Tech Solutions and CRTA Kidz — and the home of the Tech Worth Knowing blog.

## What's here

- `index.html` — the live home page.
- `worth-knowing/` — the blog articles.
- `pro-vault.html` — the CRTA Pro Vault page.
- `feather-mark.svg` — the site mark.
- `docs/START_HERE.md` — where everything lives and where to start.

## See it live

Visit https://kelli-dotcom.github.io — or open `index.html` in a browser.

Details live in `docs/START_HERE.md`.
