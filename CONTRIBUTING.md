# Contributing

## Before you change anything

1. Read `AGENTS.md` first. It holds the rules.
2. Read `docs/START_HERE.md`. It holds the idea and what the project does not do.
3. Check `mistakes.md` so you do not repeat an old mistake.

## How to contribute

1. Make one small change at a time.
2. Run `node tests/smoke.test.mjs`. It must pass.
3. Update `README.md` or `HANDOFF.md` if a person would notice the change.
4. Fill in the pull request form in `.github/pull_request_template.md`.

## What not to do

- Do not add dependencies without asking first.
- Do not commit keys, databases, uploads, or .env files.
- Do not change a brand colour without saying so plainly in the pull request.
